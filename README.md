## The entry

> It's 3am. You ate the leftovers at 2:47, blamed the dog, and the dog was asleep. I saw everything. I always do.

The fridge as a witness that snitches on the midnight snack raid — a fresh angle (no milk, no ice, no door left open), one complete line, short enough to read on a lock screen.

## Run

```sh
python3 main.py
```

Writes the text to `entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set by the grader).

Built for the make.fun bounty [The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d).
